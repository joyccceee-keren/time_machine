## 🛠️ Architecture & Tech Stack

```
time_machine/
├── index.html          # Semantic HTML5 HUD structure & CRT overlay
├── css/
│   └── style.css       # Retro-futuristic cyberpunk design system & animations
├── js/
│   ├── app.js          # Master controller, live clock sync & warp trigger
│   ├── audio.js        # Procedural Web Audio API sound synthesizer
│   ├── erasData.js     # Master timeline epoch database & lore artifacts
│   ├── journal.js      # Traveler passport, stats & LocalStorage engine
│   ├── paradoxEngine.js# Butterfly effect calculation & ripple cascade
│   └── warpEngine.js   # Canvas 2D/3D hyperspace vortex & particle engine
└── README.md           # Documentation & travel guide
```

- **Core**: Vanilla HTML5, Modern CSS3 (Grid, Flexbox, Custom Properties, Glassmorphism).
- **Graphics**: HTML5 2D/3D Projected Canvas Engine.
- **Audio**: Web Audio API (`AudioContext`, `OscillatorNode`, `BiquadFilterNode`, `GainNode`).
- **Typography**: Google Fonts (*Orbitron*, *Outfit*, *Share Tech Mono*).
- **Zero Dependencies**: Lightweight, lightning-fast, and runs locally without build steps.

## 🚀 Quickstart

Open `index.html` directly in any modern web browser, or serve with any static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```

Navigate to `http://localhost:8000` in your browser and prepare for temporal displacement!
